## 一、设计概览

### 1.1 数据库信息
| 属性 | 值 |
|------|---|
| 数据库名称 | `jn_fan_erp` |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |

### 1.2 核心实体关系

```
客户(Customer) ──┬──> 销售订单(SalesOrder) ──> 发货(Delivery) ──> 应收(Receivable)
                  │           │
                  │           └──> 生产工单(WorkOrder) ──> 工序报工(WorkReport)
                  │
供应商(Supplier) ──┴──> 采购单(PurchaseOrder) ──> 收货(Receive) ──> 质检(QualityCheck)
                                     │
                                     └──> 应付(Payable)

物料(Material) ──> BOM主表(BOM) ──> BOM明细(BOMLine) ──> 库存(Inventory)
                      │                                          │
                      └──> 生产工单(WorkOrder) ──> 工单物料需求 ──┘
```

## 三、关键表设计详解

### 3.1 物料表 (jn_material) — 风机专用属性

```sql
-- 物料基础字段
material_code    -- 编码: FN-CF-LR406-001 (类型-风机类型-型号-序号)
material_name    -- 名称: LR406离心风机整机
spec             -- 规格: Φ406
category_name    -- 分类: 成品/半成品/原材料/辅料

-- ★风机行业专用字段★
fan_type         -- 风机类型: 离心风机/轴流风机/混流风机
fan_model        -- 型号: LR406 / LR508 / AZ600 / MF355
airflow_cfm      -- 风量(CFM): 8,500
pressure_pa      -- 风压(Pa): 2,800
power_kw         -- 功率(kW): 7.5
rpm              -- 转速: 2,900
noise_dba        -- 噪音(dBA): 78
impeller_diameter -- 叶轮直径(mm): 406
weight_kg        -- 重量(kg)
is_configurable  -- 是否可选配(Y/N)
config_rules     -- 选配规则JSON
drawing_no       -- 图纸编号
version          -- 版本号(工程变更时递增)
```

### 3.2 BOM表 — 多层级 + 选配 + 版本

**BOM主表 (jn_bom)**:
- `product_id`: 关联成品物料
- `parent_bom_id`: 父BOM(子装配件也在此表)
- `version`: v1.0/v1.1/v2.0
- `status`: DRAFT→APPROVED→EFFECTIVE→DEPRECATED
- `total_cost`: 从最底层向上卷积计算的材料总成本

**BOM明细 (jn_bom_line)**:
- `parent_line_id`: 父行ID(支持子BOM嵌套)
- `material_id`: 物料ID
- `quantity`: 用量(如1台装2个叶轮则为2)
- `scrap_rate`: 损耗率(%)
- `is_optional`: 是否可选配(Y/N)
- `optional_group`: 选配组名(电机组/叶轮材质组/底座材质组)
- `optional_rule`: 选配条件规则JSON
- `default_selected`: 是否为默认选项
- `alternative_id`: 替代料

**选配规则示例** (optional_rule字段JSON):
```json
{
  "condition": "power <= 5.5",
  "matchMaterialId": 123,
  "matchMaterialName": "ABB MS631-2"
}
```

### 3.3 工序定义 (jn_process_operation) — 风机7道工序

| 序号 | 工序 | 工作中心 | 标准工时 | 是否必检 |
|------|------|----------|---------|---------|
| 1 | 下料 | 下料区 | 4.5h | 否 |
| 2 | 焊接 | 焊接区 | 8.0h | 否 |
| 3 | 动平衡 | 平衡机房 | 3.0h | **是** |
| 4 | 装配 | 装配线 | 6.0h | 否 |
| 5 | 试机 | 测试台 | 2.0h | **是** |
| 6 | 喷涂 | 喷涂房 | 3.0h | 否 |
| 7 | 包装 | 包装区 | 1.5h | 否 |

### 3.4 库存流 — 整存零取设计

```
jn_inventory (实时库存)
    ↓ 所有库存变动都必须写日志
jn_inventory_log (只增不改的流水日志)

change_type 枚举:
  PURCHASE_IN    采购入库     SALE_OUT     销售出库
  PRODUCTION_IN  生产入库     ISSUE_OUT    领料出库
  TRANSFER_IN    调拨入库     TRANSFER_OUT 调拨出库
  CHECK_IN       盘点入库     CHECK_OUT    盘点出库
  RETURN_IN      退货入库     RETURN_OUT   退货出库
  INIT_INITIAL   初始入库
```

## 四、命名规范

| 规范项 | 规则 | 示例 |
|--------|------|------|
| 数据库 | 小写+下划线 | `jn_fan_erp` |
| 表前缀 | 若依=sys_ / ERP=jn_ | `jn_sales_order` |
| 表名 | 单数 | `jn_customer` 而非 jn_customers |
| 主键 | table_id | `order_id` |
| 状态字段 | status (char/varchar) | `status='0'/'1'` |
| 删除标志 | del_flag (char) | `del_flag='0'/'1'` |
| 通用字段 | create_by/create_time/update_by/update_time | |
| 外键 | 引用表_id | `customer_id` |
| 索引 | idx_字段名 | `idx_customer_name` |
| 唯一约束 | uk_字段名 | `uk_order_no` |
