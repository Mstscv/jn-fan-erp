## 二、快速启动(开发环境)

### 2.1 启动中间件（Docker一键启动）

项目根目录下执行：

```bash
# 启动所有中间件（MySQL + Redis + Nacos + MinIO）
docker-compose -f docker/docker-compose.yml up -d

# 查看容器状态
docker ps
```

首次启动会自动执行 `sql/init.sql` 初始化数据库表结构。

### 2.2 初始化数据库

如果未使用 Docker 自动初始化，手动执行：

```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE IF NOT EXISTS jn_erp DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 退出后执行初始化脚本
mysql -u root -p jn_erp < sql/init.sql
mysql -u root -p jn_erp < sql/sprint02_biz_tables.sql
mysql -u root -p jn_erp < sql/data_migration.sql
```

### 2.3 编译项目

```bash
# 编译整个项目（跳过测试）
mvn clean install -DskipTests

# 编译单个模块
mvn clean install -pl jn-erp-modules/jn-erp-material -DskipTests
```

### 2.4 启动微服务

按依赖顺序启动以下服务（需要分别打开终端窗口或使用 IDE 启动）：

| 顺序 | 服务模块 | 端口 | 启动方式 |
|------|----------|------|----------|
| 1 | Nacos | 8848 | Docker 已自动启动 |
| 2 | `ruoyi-gateway` | 8080 | `mvn spring-boot:run -pl ruoyi-gateway` |
| 3 | `ruoyi-auth` | 9200 | `mvn spring-boot:run -pl ruoyi-auth` |
| 4 | `ruoyi-system` | 9201 | `mvn spring-boot:run -pl ruoyi-modules/ruoyi-system` |
| 5 | `jn-erp-material` | 9203 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-material` |
| 6 | `jn-erp-sales` | 9204 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-sales` |
| 7 | `jn-erp-purchase` | 9205 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-purchase` |
| 8 | `jn-erp-warehouse` | 9206 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-warehouse` |
| 9 | `jn-erp-production` | 9207 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-production` |
| 10 | `jn-erp-finance` | 9212 | `mvn spring-boot:run -pl jn-erp-modules/jn-erp-finance` |

> **提示**：也可以使用 IDE（如 IntelliJ IDEA）打开项目根目录，找到每个模块的 Application 类，右键 Run 启动。

### 2.5 启动前端

```bash
# 进入前端项目目录
cd ruoyi-ui

# 安装依赖
npm install

# 启动开发服务器（默认端口 80）
npm run dev
```

### 2.6 验证系统是否启动成功

打开浏览器访问以下地址：

```
# 后端网关（健康检查）
http://localhost:8080/actuator/health

# 前端登录页面
http://localhost

# Nacos控制台
http://localhost:8848/nacos

# Swagger接口文档
http://localhost:8080/swagger-ui/index.html
```

## 五、基础数据维护

### 5.1 物料管理

**用途**：维护风机产品及所有原材料的基本信息。

**操作步骤**：
1. 进入 **基础数据 → 物料管理**
2. 点击 **新增** 按钮
3. 填写物料信息：

```
物料编码: 自动生成（如 MAT-20260527-0001）
物料名称: 例 "LR406离心风机"
物料分类: 选择 "成品" / "半成品" / "原材料"
规格型号: 例 "LR406"
计量单位: 个/台/张/千克
风机类型: 离心式 / 轴流式 / 混流式（风机专用字段）
风量(CFM): 12000      （风机专用）
风压(Pa):  2800       （风机专用）
功率(kW):  7.5        （风机专用）
转速(RPM): 1450       （风机专用）
噪音(dBA): 75         （风机专用）
是否可选配: 是/否
安全库存:  10
单价: 根据实际填写
```

4. 点击 **保存**
5. 支持 **Excel导入**：下载模板 → 填写 → 上传导入

### 5.2 客户管理

**操作步骤**：
1. 进入 **基础数据 → 客户管理**
2. 点击 **新增**
3. 填写：

```
客户编码: 自动生成
客户名称: 例 "上海工业通风设备有限公司"
联系人: 张三
联系电话: 13800138000
地址: 上海市松江区XX路XX号
信用额度: 500000
开户行: 中国银行上海分行
银行账号: **************
```

### 5.3 供应商管理

同客户管理，额外字段：

## 六、业务操作流程

### 流程一：销售全流程（报价→订单→发货→应收）

```
客户询价 → 创建报价单 → 审核报价 → 生成销售订单 → 安排生产 → 发货出库 → 生成应收 → 收款核销
```

#### 6.1.1 创建报价单

1. 进入 **销售管理 → 报价单**
2. 点击 **新增**
3. 填写：

```
报价单号: 自动生成
客户名称: 选择已有客户 或 新增客户
报价日期: 今天
有效日期: 30天后

明细行:
  产品: LR406离心风机
  数量: 10台
  单价: 8500元
  金额: 85000元
  交货日期: 2026-07-30
```

4. 点击 **提交审核** → 主管审批通过
5. 审批通过后自动状态变为"已审核"

#### 6.1.2 生成销售订单

1. 在报价单详情页，点击 **生成订单**
2. 确认订单信息：

```
订单号: 自动生成（SO-20260527-0001）
订单日期: 今天
预计交货: 按报价单
付款方式: 30%预付款 + 70%发货前付清
运输方式: 物流托运
```

3. 点击 **确认订单**
4. 订单状态流转：待确认 → 已确认 → 生产中 → 已发货 → 已完成

#### 6.1.3 发货出库

1. 进入 **销售管理 → 发货单**
2. 点击 **新增** → 选择关联的销售订单
3. 确认发货明细（产品、数量、批次）
4. 点击 **确认发货**
5. 系统自动：
   - 创建出库单 → 扣减成品库存
   - 生成应收账款记录

#### 6.1.4 查看应收账款

1. 进入 **财务管理 → 应收账款**
2. 可看到销售发货后自动生成的应收记录
3. 点击 **收款核销** → 输入收款金额 → 完成核销
4. 核销后余额自动更新，全部核销完成则状态变为"已结清"

### 流程二：采购全流程（需求→订单→收货→质检→入库→应付）

```
物料需求 → 生成采购建议 → 创建采购订单 → 供应商确认 → 到货收货 → 来料检验 → 合格入库 → 生成应付
```

#### 6.2.1 创建采购需求

**方式一：手工创建**
1. 进入 **采购管理 → 采购需求**
2. 点击 **新增**
3. 填写需采购的物料、数量、需求日期
4. 提交审核

**方式二：MRP自动运算（推荐）**
1. 进入 **采购管理 → MRP运算**
2. 选择要展开的销售订单
3. 点击 **运行MRP**
4. 系统自动：
   - 查询销售订单 → 读取关联BOM
   - 展开BOM物料清单
   - 检查当前库存
   - 计算净需求 = BOM用量 - 现有库存
   - 生成采购需求单

#### 6.2.2 创建采购订单

1. 进入 **采购管理 → 采购订单**
2. 点击 **新增**
3. 从采购需求单引用，或手动添加：

```
采购订单号: 自动生成（PO-20260527-0001）
供应商: 选择已有供应商
采购员: 当前登录用户
订单日期: 今天
要求交货: 按需填写

明细:
  物料: 钢板 Q235 5mm    数量: 100张  单价: 450元
  物料: 电机 ABB MS631-2  数量: 10台   单价: 2800元
  物料: 轴承 SKF 6205     数量: 20个   单价: 85元
```

4. 点击 **提交审核**
5. 审核通过后状态变为"已确认"，发送给供应商

#### 6.2.3 采购收货

1. 进入 **采购管理 → 采购收货**
2. 点击 **新增** → 选择采购订单
3. 输入本次实收数量（支持部分收货）
4. 填写质量检验结果：
   - PASS → 进入待入库
   - CONDITIONAL → 让步接收
   - REJECT → 退回供应商
5. 确认收货

#### 6.2.4 来料检验（IQC）

1. 进入 **质量管理 → 来料检验**
2. 系统自动为采购收货创建检验单
3. 质检员填写检验结果：
   - 抽检数量
   - 各项检验指标实测值
   - 合格/不合格判定
4. 点击 **审批**（合格）或 **驳回**（不合格）
5. 合格 → 自动完成入库；不合格 → 自动触发退货流程

#### 6.2.5 入库

1. 进入 **仓库管理 → 入库管理**
2. 选择关联的采购收货单
3. 确认仓库、库位
4. 确认入库 → 库存增加
5. 同时生成应付账款记录

#### 6.2.6 查看应付账款

1. 进入 **财务管理 → 应付账款**
2. 可看到采购入库后自动生成的应付记录
3. 点击 **付款核销** → 选择付款方式 → 完成付款
4. 核销后余额更新

### 流程三：BOM管理（产品结构定义）

```
创建BOM → 添加物料行 → 设置选配规则 → 审核生效 → 版本管理 → 成本卷积
```

#### 6.3.1 创建BOM

1. 进入 **BOM管理 → BOM维护**
2. 点击 **新增**

```
BOM名称: LR406离心风机标准BOM
关联产品: 选择 LR406离心风机
版本: v1.0（自动生成）
生效日期: 今天
失效日期: 空（长期有效）
```

3. 添加BOM明细行（LR406风机典型BOM结构）：

```
层级0 - 整机:
  组件1: 叶轮组
    - 叶轮(铸铝)               ×1   位号: IMP-001
    - 轴套                     ×1   位号: SLE-001
    - 平衡块                   ×2   位号: BAL-001
  组件2: 蜗壳组
    - 蜗壳                     ×1   位号: VOL-001
    - 进风口                   ×1   位号: INL-001
    - 出风口法兰               ×1   位号: FLG-001
  组件3: 电机组(选配)
    - [可选] ABB电机MS631-2    ×1   选配组: 功率匹配 (功率<=5.5kW)
    - [可选] ABB电机MS801-2    ×1   选配组: 功率匹配 (5.5<功率<=15kW)
    - [可选] 西门子电机1LE0    ×1   选配组: 功率匹配 (功率>15kW)
  组件4: 底座组
    - [可选] 碳钢底座          ×1   选配组: 底座材质
    - [可选] 不锈钢底座         ×1   选配组: 底座材质
    - 减震器                   ×4
```

4. 点击 **保存**（状态: 草稿）

#### 6.3.2 配置选配规则

1. 在BOM编辑页面，点击选配组名称
2. 设置选配规则：

```
选配组: 功率匹配
适用条件: 根据订单功率自动匹配
规则:
  IF 功率 <= 5.5kW  THEN 默认选择 ABB电机MS631-2
  IF 5.5 < 功率 <= 15kW  THEN 默认选择 ABB电机MS801-2
  IF 功率 > 15kW  THEN 默认选择 西门子电机1LE0
```

#### 6.3.3 BOM审核

1. 在BOM列表页，选择状态为"草稿"的BOM
2. 点击 **审核** → 状态变为"已审核"
3. 点击 **生效** → 状态变为"已生效"
4. 生效后即可用于生产工单

#### 6.3.4 BOM成本卷积

1. 在BOM详情页，点击 **计算成本**
2. 系统自动从最底层向上卷积：
   - 叶轮成本 = 材料单价 × 数量 × (1 + 损耗率)
   - 蜗壳成本 = 材料单价 × 数量
   - 电机成本 = 电机单价 × 数量
   - 总成本 = 各组件成本之和
3. 结果自动更新到BOM的"总成本"字段

#### 6.3.5 BOM版本管理

1. 进入 **BOM管理 → BOM版本**
2. 可查看当前BOM的所有历史版本
3. 点击 **复制** → 从已有BOM复制生成新版本
4. 修改后保存为 v1.1 或 v2.0

## 八、常见问题

### Q1: 启动时提示端口被占用

```bash
# 查看端口占用
netstat -ano | findstr :8080

# 强制结束占用进程（Windows）
taskkill /F /PID <进程ID>
```

### Q2: 数据库连接失败

1. 检查 MySQL 是否启动：`docker ps | grep mysql`
2. 检查数据库名称 `jn_erp` 是否存在
3. 检查 `bootstrap.yml` 中的用户名和密码是否正确
4. 检查 MySQL 是否允许远程连接

### Q3: Maven依赖下载失败

```bash
# 清理本地缓存重新下载
mvn clean install -DskipTests -U

# 检查 settings.xml 的 mirror 配置
```

### Q4: Nacos连接失败

1. 确认 Nacos 容器在运行：`docker ps | grep nacos`
2. 访问 http://localhost:8848/nacos 确认控制台可用
3. 检查应用配置文件中的 Nacos 地址

### Q5: 前端页面白屏或404

1. 确认网关服务已启动（端口 8080）
2. 打开浏览器开发者工具（F12）→ Network 标签
3. 检查 API 请求是否返回 200
4. 尝试刷新页面或清除浏览器缓存

### Q6: 如何重置管理员密码

```sql
-- 登录MySQL执行
UPDATE sys_user SET password = '$2a$10$7JB720yubVSZvUI0rEqK/.VqGOZTH.ulu33dHOiBE8ByOhJIrdAu2' 
WHERE user_name = 'admin';
-- 密码重置为: admin123
```

### Q7: 备份与恢复

```bash
# 备份数据库
docker exec jn-erp-mysql mysqldump -u root -p jn_erp > backup_$(date +%Y%m%d).sql

# 恢复数据库
docker exec -i jn-erp-mysql mysql -u root -p jn_erp < backup_20260527.sql
```

### Q8: 各服务日志查看

```bash

docker logs jn-erp-production -f --tail 100

tail -f logs/jn-erp-production/info.log
```
